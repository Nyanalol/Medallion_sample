# Create a Planning sheet

					
		
			 
				
					
		
			
				
			
			Feedback
		
	
				

		  
		

	 
		
			
				
					
				
				
					
						Summarize this article for me
					
				
			

			
			

		

	 
		
			
				In this article
			
		
	
					This article describes how to get started with your first Planning sheet in plan (preview).

Important

This feature is in preview.

## Prerequisites

Before you set up Planning sheets, make sure you have the following prerequisites:

- Data in a Power BI semantic model, and a connection to your semantic model.

- Data in a Fabric SQL database, and a connection to your database

Note

The preview of plan in Fabric IQ is now accessible to organizations worldwide in Microsoft Fabric as part of the Microsoft Fabric SKU, and new meters have been created. Meters are currently available but are not currently billed.

## Create plan item

Start in your Fabric workspace.

Create a **New item > Plan (preview)**.

Name your plan and **Create** it.

Note

During planning item creation, a Fabric SQL database is automatically created in your workspace. This database stores your plan report's metadata.

## Create a Planning sheet

In your new plan item, you see options to get your data from the semantic model or Excel/CSV and create a Planning sheet from it, or to start with a Planning sheet and then connect it to data.

Select **Planning**, **Name** the new Planning sheet, and **Create** it.

## Connect Planning sheet to a dataset

In your new Planning sheet, select **Add** and **Connect** to your semantic model connection.

Select the semantic model and select **Add**.

Add semantic model data into your fields. Now your first Planning sheet is created.
