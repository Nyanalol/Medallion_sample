# Export high-quality PDF & Excel reports

					
		
			 
				
					
		
			
				
			
			Feedback
		
	
				

		  
		

	 
		
			
				
					
				
				
					
						Summarize this article for me
					
				
			

			
			

		

	 
		
			
				In this article
			
		
	
					Export reports and dashboards as high-quality files while preserving layout and formatting. Export options allow you to:

- Export charts, tables, and dashboards as **PDF or PNG** files.

- Preserve report formatting, including fonts, colors, spacing, and layout.

- Select the quality and page size.

Important

This feature is in preview.

## Export data

To export the data used in the chart, select and hold (or right-click) the visual, select **Export**, then select **Data**. The underlying data is saved as a CSV file.

## Export to PDF

Select **Export to PDF**.

Set the **Page Size**.

Choose **Landscape** or **Portrait** orientation.

Select the export resolution (4K/1080p/720p).

Select the link to download the PDF file.

## Export to Excel

Tabular reports can be exported to Excel with fully preserved conditional formatting.

Select the columns in your report to export only those columns. By default, the entire matrix is exported.

Select the **Export** icon on the **Home** tab of the menu ribbon.

Select **Excel** format.

Choose **Selected Columns** (this exports a portion of the report).

Select **Export**.

To download the file, select the link.
